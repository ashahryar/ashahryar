## 👋 About Me

I'm a **Computer Science graduate (2026)** and **Data Engineer** who builds batch ETL/ELT pipelines with **Python, SQL and Apache Airflow** on **AWS**. I care about pipelines that are **tested, monitored and automated**, not just pipelines that run once.

- 🛠️ Data engineering internships at **JBS** and **Zaitoon Ashraf IT Park (Saylani)**
- 🌊 Built a pipeline that turns Pakistani disaster and weather reports into live dashboards
- 🚢 Adding **CI/CD** (Docker, Terraform, GitHub Actions) to data projects
- 🤖 Built a **RAG** system, so I can prepare data for AI applications
- 🔬 Research interests: **time-series forecasting** and **machine learning for hydrological and disaster-risk data**
